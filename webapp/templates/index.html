About This Project

Dataset

Trained on VisDrone2019-DET with 6,471 training images and 343K annotated objects across 10 classes.

Model

YOLOv8s fine-tuned for 50 epochs using AdamW optimizer, mosaic augmentation, and multi-scale detection heads.

Tracking

ByteTrack multi-object tracking assigns persistent IDs and trajectory trails across video frames.

Stack

Python · PyTorch · Ultralytics · OpenCV · Flask · Deployed with real-time GPU inference.
